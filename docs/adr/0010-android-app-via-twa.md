# 10. Android app on Google Play via a Trusted Web Activity

Date: 2026-11-25

## Status

Proposed (the conversion runs when the owner asks for it; see `docs/store/android-twa.md`)

## Context

The course should be on Google Play. It is a Next.js site with server routes on Vercel; rewriting it as a native or React Native app would duplicate all UI and content.

## Decision

Wrap the deployed site in a Trusted Web Activity built with Bubblewrap. The site provides what the wrapper needs: `app/manifest.ts`, PNG icons in `public/icons/` (generated by `pnpm icons` from `app/icon.svg`), and `/.well-known/assetlinks.json` (rewrite to `app/api/assetlinks/route.ts`, values from env vars). Store policy pieces live in the site itself: the "not affiliated with Anthropic" notice in the footer, the privacy policy at `/uk/privacy`, and in-app account deletion (`DELETE /api/account`).

## Consequences

- Content and UI updates ship by deploying the site; the app only needs a new build when the manifest, icon, domain or package changes.
- The production domain must be final before the first build: it is baked into the app and the asset links.
- Google sign-in must be tested inside the TWA on a real device.
- Store texts and Data safety answers are kept in `docs/store/play-console.md` and must change when the app starts collecting new data.
