<TLDR>
- Чат — для питань, текстів і роботи з одним-двома документами. Ти робиш кроки, Claude допомагає.
- <Term id="agent">Агент</Term> — коли задача багатокрокова: обробити десятки файлів, змінити код, довести роботу до готового результату.
- Для некодових задач є <Term id="cowork" />, для коду в репозиторії — <Term id="claude-code" />.
</TLDR>

## Головне питання: хто робить кроки?

У чаті ти ведеш розмову: питаєш, отримуєш відповідь, сам переносиш результат куди треба. Агент отримує **ціль** і сам виконує кроки: відкриває файли, запускає дії, перевіряє результат, повторює. Детальніше про цей цикл — в уроці про <Term id="agentic-loop" /> з модуля про Claude Code.

## Що де працює

| Інструмент | Найкраще для | Приклад |
| --- | --- | --- |
| Чат | Питання, тексти, аналіз одного документа | «Поясни цей пункт договору» |
| <Term id="claude-project" /> | Повторювана робота з тим самим контекстом | Відповіді клієнтам за FAQ |
| <Term id="research-mode" /> | Глибокий пошук з багатьох джерел | Огляд ринку чи конкурентів |
| <Term id="cowork" /> | Багатокрокова некодова робота з файлами, документами, браузером | «Розклади 40 рахунків у таблицю Excel» |
| <Term id="claude-code" /> | Зміни в коді проєкту, тести, git | «Додай імпорт рахунків у бекенд і тести» |

<Callout type="tip" title="Cowork коротко">
Cowork переносить підхід Claude Code на некодові задачі: описуєш результат, а Claude планує й виконує кроки без терміналу. Сесії йдуть у хмарі й продовжуються, навіть якщо закрити ноутбук. Задачі з локальними файлами чи браузером виконуються через застосунок Claude Desktop. Потрібен платний тариф.
</Callout>
