<TLDR>
- <Term id="mcp" /> — стандарт, через який Claude Code отримує нові інструменти: Sentry, GitHub, Jira, бази даних, браузер. Додав сервер, і в агента з'явилися нові «руки».
- Додаються командою `claude mcp add`: віддалені через `--transport http`, локальні через `--transport stdio` і команду після `--`.
- Підключай лише сервери, яким довіряєш: сервер із зовнішнім контентом — шлях для <Term id="prompt-injection" />.
</TLDR>

## Що дає MCP

Без MCP агент бачить лише твій код і термінал. З MCP він може сам подивитися помилки в Sentry, задачу в Jira, макет у Figma чи схему бази, тобто зробити те, що зазвичай ти копіюєш руками в чат.

Кожен сервер додає набір інструментів з іменами виду `mcp__<server>__<tool>`, наприклад `mcp__sentry__search_issues`. Їх можна дозволяти чи забороняти в правилах <Term id="permissions">дозволів</Term> і ловити в <Term id="hook">хуках</Term>.

## Як додати сервер

**Віддалений** (хмарні сервіси, рекомендований варіант):

```bash
claude mcp add --transport http sentry https://mcp.sentry.dev/mcp
claude mcp add --transport http notion https://mcp.notion.com/mcp
```

**Локальний** <Term id="stdio" /> (програма на твоїй машині). Усе після `--` передається серверу як є:

```bash
claude mcp add --transport stdio db -- npx -y @bytebase/dbhub \
  --dsn "postgresql://readonly:pass@localhost:5432/analytics"
```

Далі в сесії `/mcp`: там видно статус кожного сервера, там же проходиш вхід через OAuth, якщо сервер його просить. Корисні команди: `claude mcp list`, `claude mcp get <name>`, `claude mcp remove <name>`.

<Callout type="tip" title="Для бази — read-only користувач">
Агенту для аналізу даних не потрібні права на запис. Окремий користувач лише з читанням — найпростіший захист від випадкового `DROP`.
</Callout>

## Scopes: для кого сервер

| Scope | Прапорець | Де зберігається | Хто бачить |
| --- | --- | --- | --- |
| local (типово) | `--scope local` | `~/.claude.json`, під шляхом проєкту | Лише ти, лише цей проєкт |
| project | `--scope project` | `.mcp.json` у корені проєкту | Уся команда через git |
| user | `--scope user` | `~/.claude.json` | Ти, у всіх проєктах |

Командний `.mcp.json` виглядає так:

```json
{
  "mcpServers": {
    "sentry": {
      "type": "http",
      "url": "https://mcp.sentry.dev/mcp"
    },
    "db": {
      "command": "npx",
      "args": ["-y", "@bytebase/dbhub", "--dsn", "${DB_READONLY_URL}"]
    }
  }
}
```

`${DB_READONLY_URL}` підставиться зі змінних середовища, тож пароль не потрапить у репозиторій. Сервери з `.mcp.json` Claude Code спершу попросить схвалити, перш ніж запускати.
