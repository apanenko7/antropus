## Навіщо окремий контекст

Пошук по великому проєкту — це десятки прочитаних файлів. Якщо їх читає головна сесія, контекст забивається сміттям, і на основну задачу лишається менше уваги. Субагент читає все у **своєму** вікні й повертає лише висновок.

Субагент **не бачить** твоєї розмови. Claude пише йому коротке доручення, і той працює від нього. Тому корисно, щоб завдання було самодостатнім.

## Вбудовані субагенти

| Субагент | Що робить | Може змінювати файли? |
| --- | --- | --- |
| **Explore** | Швидко шукає й аналізує код, є рівні ретельності: quick, medium, very thorough | Ні, лише читання |
| **Plan** | Дослідження для плану в plan mode | Ні, лише читання |
| **general-purpose** | Складні багатокрокові задачі: і дослідити, і зробити | Так |

Найчастіше Claude делегує сам. Можна й попросити прямо: «use a subagent to find all places where we call the payments API».

## Свій субагент

Файл `.claude/agents/code-reviewer.md` (для всієї команди) або `~/.claude/agents/code-reviewer.md` (для тебе в усіх проєктах):

```markdown
---
name: code-reviewer
description: Reviews code for quality and security. Use proactively after writing or modifying code.
tools: Read, Glob, Grep
model: sonnet
---

You are a senior code reviewer. Check correctness, security and naming.
Reply with a list of issues, each with file:line and a suggested fix.
```

| Поле | Значення |
| --- | --- |
| `name` | Унікальний ідентифікатор. Обов'язкове |
| `description` | Коли делегувати. Обов'язкове. «Use proactively» підштовхує Claude звертатися частіше |
| `tools` | Список інструментів через кому. Якщо не вказати, успадковує всі |
| `model` | `sonnet`, `opus`, `haiku`, `fable`, повний ID або `inherit` |

Текст після frontmatter стає **системним промптом** субагента. Зміни у файлі підхоплюються зазвичай без перезапуску.

<Callout type="tip" title="Мінімум прав">
Рев'юеру не потрібні Edit і Write, досліднику — Bash. Обмежений `tools` = менше ризику, що субагент зробить зайве.
</Callout>

## Як викликати

- **Автоматично:** Claude делегує за `description`.
- **Словами:** «use the code-reviewer subagent on the auth changes».
- **Через @:** `@agent-code-reviewer` у повідомленні.
- **Уся сесія як цей агент:** `claude --agent code-reviewer`.
