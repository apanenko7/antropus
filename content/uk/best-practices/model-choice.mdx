<TLDR>
- За замовчуванням <Term id="opus" /> з <Term id="effort" /> `medium` — цього вистачає для більшості щоденної роботи.
- Effort — головний регулятор «скільки думати»: `low` для швидких ітерацій, `high`/`xhigh` для підступних задач, `max` — рідко.
- Рахуй вартість **виконаної задачі**, а не одного запиту: дешевий запит, що потребує трьох переробок, не дешевий.
</TLDR>

## Чотири моделі — чотири ролі

| Модель | Для чого | Відносна ціна (листопад 2026) |
| --- | --- | --- |
| <Term id="fable" /> 5.2 | Найскладніші й найдовші задачі, глибокі міркування без нагляду | Найдорожча, приблизно ×2 від Opus |
| <Term id="opus" /> 5.5 | Модель за замовчуванням: більшість коду, агенти, аналіз | Базова |
| <Term id="sonnet" /> 5.5 | Рутинний код і тексти великими обсягами | Приблизно вдвічі дешевша за Opus |
| <Term id="haiku" /> 5.5 | Прості масові задачі, допоміжні субагенти | У десятки разів дешевша |

У <Term id="claude-code" /> модель змінюється командою `/model`: `/model sonnet`, `/model fable`, або `/model` без аргументу — відкриється вибір. Є й комбінований псевдонім `opusplan`: Opus у <Term id="plan-mode" />, Sonnet для виконання плану.

## Effort: скільки думати

<Term id="effort">Effort</Term> керує тим, наскільки глибоко модель міркує перед відповіддю. Рівні: `low`, `medium`, `high`, `xhigh`, `max`. У Fable 5.2, Opus 5.5, Sonnet 5.5 і Haiku 5.5 за замовчуванням стоїть `medium`.

<Steps items={[
  { title: "low", text: "Мозковий штурм, чернетка, перейменування — ти все одно перевіряєш кожен крок." },
  { title: "medium", text: "Звичайна фіча з чіткими рамками. Стоїть за замовчуванням не просто так." },
  { title: "high / xhigh", text: "Баг у чужому коді, плаваючий тест, зміна схеми, де треба знайти всі місця використання." },
  { title: "max", text: "Важка задача без твоєї участі, наприклад пошук вразливості. На звичайних задачах «передумує» за ваші гроші." },
]} />

Змінюється через `/effort high` (або `/effort` — повзунок). Якщо глибше подумати треба лише над одним питанням посеред рутини, додай у промпт слово <Term id="ultrathink" /> — це не змінює налаштування для всієї сесії.

<Callout type="warn" title="«Думай краще» не працює">
Фрази «think harder», «будь ретельним» — це звичайний текст, а не перемикач. Глибину задає effort. Ultrathink — виняток: він справді просить глибше подумати на одному кроці.
</Callout>

## Дешевше на субагентах

<Term id="subagent">Субагенти</Term>, які успадковують модель сесії, працюють на ній же — тобто на Opus, якщо ти на Opus. Для простої роботи (зібрати файли, що імпортують модуль; перевірити посилання) пропиши у визначенні субагента `model: haiku`.
