## Чекліст «раз і назавжди»

| Що | Навіщо | Як |
| --- | --- | --- |
| <Term id="claude-md" /> | Команди перевірки й пастки проєкту | `/init`, далі скорочуй до ~200 рядків |
| <Term id="permissions">Дозволи</Term> | Не підтверджувати тести й lint щоразу | Allow-правила в <Term id="settings-json" />; небезпечне лишається на підтвердження |
| <Term id="hook">Хук</Term>-форматер | Код завжди відформатований без нагадувань | Хук після кожного редагування файлу |
| 1–2 <Term id="skill">skills</Term> | Повторювані процеси: реліз, рев'ю, звіт | `.claude/skills/назва/SKILL.md` |
| Лише потрібні <Term id="mcp" />-сервери | Менше шуму в контексті | `/mcp` — вимкни те, чим не користуєшся |
| <Term id="status-line" /> | Модель і заповнення контексту завжди перед очима | `/statusline` + опис словами |
| IDE | Diff-и прямо в редакторі | Розширення для VS Code чи JetBrains |
| <Term id="git" /> | Будь-яку зміну можна відкотити | Коміт перед великою задачею, worktree для паралельної роботи |

<Callout type="tip" title="Особисте — окремо">
Командні правила — у CLAUDE.md, що комітиться. Твої особисті вподобання — у `CLAUDE.local.md` (додай у `.gitignore`) або в `~/.claude/CLAUDE.md` для всіх проєктів.
</Callout>

## Клавіші, які варто знати напам'ять

| Клавіша | Що робить |
| --- | --- |
| `Shift+Tab` | Перемикає режими дозволів, зокрема <Term id="plan-mode" /> |
| `Esc` | Зупиняє агента, зберігаючи все зроблене |
| `Esc` `Esc` | На порожньому рядку — меню <Term id="rewind" />: відкат коду й розмови |
| `Ctrl+B` | Відправляє довгу команду чи агента у фон |
| `Ctrl+R` | Пошук по історії твоїх промптів |
| `Ctrl+G` | Відкрити промпт у текстовому редакторі |
| `!` на початку | Виконати shell-команду й показати результат Claude |
| `@` | Підставити шлях до файлу в промпт |
