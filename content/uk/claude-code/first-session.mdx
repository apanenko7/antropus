<TLDR>
- Встанови однією командою, перейди в папку проєкту й набери `claude`; на першому запуску він попросить увійти.
- Перша сесія — це питання, а не зміни: нехай Claude спершу пояснить, як влаштований проєкт.
- Починай з маленької зміни й завжди переглядай <Term id="diff" />, перш ніж погодитися.
</TLDR>

## Встановлення

Потрібні термінал, проєкт і підписка Claude (Pro, Max, Ultra, Team чи Enterprise) або акаунт Claude Console. Рекомендований спосіб — нативний інсталятор:

```bash
# macOS, Linux, WSL
curl -fsSL https://claude.ai/install.sh | bash

# Windows PowerShell
irm https://claude.ai/install.ps1 | iex
```

Є й варіанти через Homebrew (`brew install --cask claude-code`) та WinGet (`winget install Anthropic.ClaudeCode`). Перевір: `claude --version` має вивести номер версії.

<Callout type="tip" title="Windows">
На Windows встанови Git for Windows: тоді агент зможе користуватися Bash. Без нього Claude Code працює через PowerShell.
</Callout>

## Перший запуск

```bash
cd ~/projects/shop
claude
```

На першому запуску відкриється браузер для входу. Над полем вводу ти побачиш версію, поточну модель і робочу папку. Агент бачить саме цю папку та її підпапки, тож запускай його в корені проєкту, а не в домашній теці.

<Callout type="pro" title="Корисні варіанти запуску">
`claude "полагодь білд"` — одразу з задачею. `claude -c` — продовжити останню розмову в цій папці. `claude -r` — обрати, яку розмову відновити.
</Callout>

## Спочатку питання

Не треба вручну «згодовувати» файли: Claude читає те, що потрібно, сам. Почни з розвідки:

- «що робить цей проєкт?»
- «які технології тут використовуються?»
- «де головна точка входу?»
- «поясни структуру папок»

Так ти перевіриш, що агент правильно зрозумів проєкт, а він збере контекст для наступних задач.

## Перша зміна й перегляд diff

Обери щось маленьке й безпечне: додати функцію, змінити текст, виправити дрібний баг. Claude знайде файл і покаже зміну як <Term id="diff" />: рядки з `+` додаються, з `−` видаляються.
