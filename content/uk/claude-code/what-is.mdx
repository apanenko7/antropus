<TLDR>
- <Term id="claude-code" /> — це не чат про код, а <Term id="agent">агент</Term>: він сам читає файли, запускає команди й змінює код у твоєму проєкті.
- Він працює циклом: зібрати контекст → діяти → перевірити, і повторює його, доки задачу не виконано.
- Той самий агент доступний у терміналі, VS Code, JetBrains, десктоп-застосунку та вебі.
</TLDR>

## Чат проти агента

У звичайному чаті ти копіюєш код у вікно, отримуєш відповідь і сам вставляєш її назад. Модель бачить лише те, що ти їй показав, і нічого не може перевірити.

<Term id="claude-code" /> працює **прямо в папці проєкту**. Він бачить усі файли, твій <Term id="git" />-стан і термінал. Тому ти ставиш ціль («полагодь тест»), а не диктуєш кроки: які файли відкрити й що запустити, він вирішить сам.

## Агентний цикл

Будь-яку задачу Claude Code виконує через <Term id="agentic-loop" />: три фази, що повторюються.

Питання про код може обмежитися першою фазою, а виправлення бага пройде цикл кілька разів. Ти теж частина циклу: можеш перервати агента будь-якої миті й скерувати інакше.

## Інструменти — це руки агента

Без інструментів модель уміє лише писати текст. Через <Term id="tool-use" /> вона діє. Вбудовані інструменти бувають п'яти видів:

| Категорія | Що робить |
| --- | --- |
| Файли | читає, редагує, створює файли |
| Пошук | шукає файли за шаблоном і текст у коді |
| Виконання | запускає команди, тести, сервери, git |
| Веб | шукає в інтернеті, читає документацію |
| Code intelligence | бачить помилки типів, переходить до визначень (через плагіни) |

Кожен виклик інструмента повертає результат, і на його основі агент вирішує наступний крок. Можливості можна розширювати: <Term id="mcp" /> підключає зовнішні сервіси, а <Term id="skill">skills</Term> додають готові процедури.

## Де він працює

Цикл і інструменти скрізь однакові, різниться лише інтерфейс:

- **Термінал** — класичний <Term id="cli" />: команда `claude` у папці проєкту.
- **<Term id="ide" />** — розширення для VS Code і JetBrains, diff-и прямо в редакторі.
- **Десктоп-застосунок** — кілька сесій поруч.
- **Веб** — claude.ai/code, сесії в хмарі, навіть без локальної копії репозиторію.

<Callout type="tip" title="Делегуй, а не диктуй">
Став задачу як здібному колезі: дай контекст і ціль, а деталі («відкрий файл X, запусти Y») залиш агентові. Наприклад: «Оплата не проходить для прострочених карток, код у src/payments/. Розберись і виправ».
</Callout>
