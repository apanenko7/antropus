<TLDR>
- Усе, що бачить агент у сесії (розмова, прочитані файли, вивід команд), лежить у <Term id="context-window" />. Кожна нова сесія стартує з чистого.
- `/clear` — нова розмова між задачами, <Term id="compact" /> — стиснути історію посеред задачі.
- `@файл` дає файл одразу, `!команда` виконує команду сам, а `claude -c` повертає вчорашню розмову.
</TLDR>

## Контекст сесії

У <Term id="context-window" /> потрапляють твої повідомлення, відповіді, вміст прочитаних файлів, вивід команд, <Term id="claude-md" /> і системні інструкції. Коли вікно наповнюється, Claude Code **автоматично стискає** розмову в підсумок. Запити й ключові шматки коду лишаються, а от детальні інструкції з початку можуть загубитися.

Тому постійні правила тримай у <Term id="claude-md" />, а не в першому повідомленні сесії. Подивитися, що займає місце, можна командою `/context`.

<Callout type="tip" title="Фокус важливіший за розмір">
У сучасних моделей вікно велике, і впертися в ліміт складно. Але сфокусований контекст дає кращі відповіді й коштує менше. Тож нова задача — нова розмова.
</Callout>

## /clear проти /compact

| | `/clear` | `/compact` |
| --- | --- | --- |
| Що робить | починає нову порожню розмову | замінює історію коротким підсумком |
| Коли | перейшов до іншої, не пов'язаної задачі | та сама задача, але історія розрослася |
| Повернутися | `/resume` покаже попередню розмову | історія вже стиснута |

`/compact` приймає підказку, що зберегти: `/compact залиш рішення щодо API і список змінених файлів`.

<Callout type="pro" title="Правило двох спроб">
Якщо ти двічі поправив агента, а результат усе ще не той, третя поправка рідко допомагає: у контексті вже дві невдалі спроби. Зроби `/clear` і напиши один кращий промпт з урахуванням того, що дізнався.
</Callout>

## Швидкі префікси

- **`@шлях`** — додати файл чи папку в повідомлення одразу: `поясни @src/lib/retry.ts`. Працює автодоповнення шляхів.
- **`!команда`** — <Term id="cli">shell</Term>-режим: команда виконується напряму, без агента, а її вивід потрапляє в розмову. Зручно для `! git status` чи `! npm test`.
- **`/`** — меню <Term id="slash-command">slash-команд</Term> і skills; друкуй літери, щоб фільтрувати.

## Команди на щодень

| Команда | Навіщо |
| --- | --- |
| `/help` | список команд |
| `/init` | створити чернетку <Term id="claude-md" /> для проєкту |
| `/memory` | редагувати CLAUDE.md і керувати авто-пам'яттю |
| `/model` | змінити модель (і рівень <Term id="effort" />, якщо модель його підтримує) |
| `/context` | побачити, чим зайнятий контекст |
| `/usage` (або `/cost`) | вартість сесії та ліміти плану |
| `/diff` | переглянути всі зміни в робочій копії |
| `/rewind` | відкотити код і/або розмову |
| `/btw` | поставити побічне питання, не засмічуючи історію |

## Повернутися до розмови

Розмови зберігаються локально, тож завтра можна продовжити з того самого місця:

- `claude -c` (`--continue`) — продовжити **останню** розмову в цій папці;
- `claude -r` (`--resume`) — обрати розмову зі списку, або `/resume` усередині сесії;
- `/rename назва` — дати сесії ім'я, щоб потім відновити: `claude --resume назва`.
