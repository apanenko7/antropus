<TLDR>
- <Term id="tool-use" />: ти описуєш функції (назва, опис, JSON-схема), модель вирішує, яку викликати, а **виконує їх твій код**.
- Цикл: відповідь з `stop_reason: "tool_use"` → виконуєш функцію → повертаєш `tool_result` → модель відповідає далі.
- Коли потрібен просто JSON у відповідь, бери <Term id="structured-outputs" />: `output_config.format` гарантує відповідність схемі.
</TLDR>

## Як працює tool use

Модель не має доступу до твоєї бази чи сервісів. Але ти можеш дати їй **меню інструментів**:

```ts
const tools = [
  {
    name: "get_order_status",
    description: "Повертає статус і очікувану дату доставки замовлення за його номером. Використовуй, коли клієнт питає про своє замовлення.",
    input_schema: {
      type: "object",
      properties: { order_id: { type: "string", description: "Номер замовлення, напр. 1842" } },
      required: ["order_id"],
    },
  },
];
```

```ts
for (const block of response.content) {
  if (block.type === "tool_use") {
    const result = await getOrderStatus(block.input.order_id);
    messages.push({ role: "assistant", content: response.content });
    messages.push({
      role: "user",
      content: [{ type: "tool_result", tool_use_id: block.id, content: JSON.stringify(result) }],
    });
  }
}
```

<Callout type="tip" title="Описи — це промпт">
Модель обирає інструмент за `name` і `description`. «Отримати дані» — погано. «Повертає статус замовлення за номером; використовуй, коли клієнт питає про доставку» — добре. Детальніше — у модулі «Архітектура агентів».
</Callout>

Кілька порад:
- Якщо модель викликала кілька інструментів одразу, поверни **усі** `tool_result` в одному повідомленні `user`.
- Помилку інструменту повертай як `tool_result` з `is_error: true`, а не мовчки пропускай.
- Аргументи завжди розбирай як JSON-об'єкт, не порівнюй рядки.
- Додай `strict: true` до визначення інструменту, щоб аргументи гарантовано відповідали схемі.

## Structured outputs: просто дай JSON

Якщо інструменти не потрібні, а потрібна відповідь у певній формі (витягти поля з листа, класифікувати), використовуй <Term id="structured-outputs" />:

```ts
import { z } from "zod";
import { zodOutputFormat } from "@anthropic-ai/sdk/helpers/zod";

const Contact = z.object({ name: z.string(), email: z.string(), plan: z.string() });

const res = await client.messages.parse({
  model: "claude-opus-5-5",
  max_tokens: 1024,
  messages: [{ role: "user", content: "Витягни контакт: Олена Коваль, olena@co.ua, тариф Pro" }],
  output_config: { format: zodOutputFormat(Contact) },
});

console.log(res.parsed_output?.email);
```

| Потрібно | Бери |
| --- | --- |
| Модель має отримати дані чи зробити дію у твоїй системі | tool use |
| Відповідь у фіксованій JSON-структурі | structured outputs |
| Агент, що сам кличе інструменти багато разів | tool use + цикл (або Tool Runner у SDK) |
