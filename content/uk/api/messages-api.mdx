<TLDR>
- Усе спілкування з Claude з коду йде через один ендпоінт — <Term id="messages-api" />: ти шлеш історію повідомлень, отримуєш відповідь.
- Обов'язкові поля: `model`, <Term id="max-tokens" />, `messages`; інструкції — в окремому полі `system`.
- API не пам'ятає розмову: кожен запит містить усю потрібну історію, а <Term id="api-key">ключ</Term> живе лише на сервері.
</TLDR>

## Як це влаштовано

<Term id="api">API</Term> — це спосіб викликати Claude з власного застосунку: бота, сервісу, скрипта. Замість чату в браузері твій код надсилає HTTP-запит і отримує JSON. Оплата — за <Term id="token">токени</Term> входу й виходу.

Для TypeScript є офіційний <Term id="sdk">SDK</Term> — `@anthropic-ai/sdk`. Він сам підставляє ключ із середовища, робить повтори при тимчасових помилках і дає типи.

## Мінімальний запит

```ts
import Anthropic from "@anthropic-ai/sdk";

const client = new Anthropic(); // бере ANTHROPIC_API_KEY із середовища

const response = await client.messages.create({
  model: "claude-opus-5-5",
  max_tokens: 16000,
  system: "Ти — помічник служби підтримки. Відповідай коротко, українською.",
  messages: [{ role: "user", content: "Яка столиця України?" }],
});

for (const block of response.content) {
  if (block.type === "text") console.log(block.text);
}
```

| Поле | Навіщо |
| --- | --- |
| `model` | яка модель відповідає; за замовчуванням бери `claude-opus-5-5` |
| `max_tokens` | стеля довжини відповіді (обов'язкове) |
| `system` | <Term id="system-prompt">системний промпт</Term>: роль, правила, тон |
| `messages` | історія: чергуються `user` і `assistant` |

У відповіді дивись на три речі: `content` (масив блоків — текст, виклики інструментів), <Term id="stop-reason" /> і `usage` (скільки токенів витрачено).

## Розмова = ти передаєш історію

API **stateless**: він не пам'ятає попередні запити. Щоб продовжити діалог, надсилаєш усю історію знову:

```ts
const messages = [
  { role: "user", content: "Мене звати Оля." },
  { role: "assistant", content: "Привіт, Олю!" },
  { role: "user", content: "Як мене звати?" },
];
```

<Callout type="warn" title="Без «підказки» відповіді">
На нових моделях (Claude 4.6 і новіші) не можна закінчувати `messages` повідомленням `assistant`, щоб «почати відповідь за модель» (<Term id="prefill">prefill</Term>) — API поверне помилку 400. Формат задавай інструкцією або через <Term id="structured-outputs" />.
</Callout>

## Ключ і безпека

- Ключ створюєш у Console і кладеш у змінну `ANTHROPIC_API_KEY` на сервері.
- **Ніколи** не вшивай ключ у фронтенд: будь-хто відкриє DevTools і витратить твої гроші.
- Браузер ходить до твого бекенду, бекенд — до Claude.
