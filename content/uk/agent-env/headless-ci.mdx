## Агент без інтерфейсу

Інтерактивна сесія — це розмова. Але багато задач розмови не потребують: «поясни помилку збірки», «знайди опечатки в diff», «полагодь lint». Для них є прапорець `-p` (або `--print`):

```bash
claude -p "What does the auth module do?"
```

Claude Code виконує задачу, друкує результат і завершується. Код виходу `0` означає успіх, не нуль — збій, тож скрипт може на це реагувати.

## Основні прапорці

| Прапорець | Навіщо |
| --- | --- |
| `-p`, `--print` | Неінтерактивний запуск |
| `--output-format text \| json \| stream-json` | Звичайний текст, JSON з `result`, `session_id` і вартістю, або потік подій |
| `--json-schema '…'` | Відповідь за схемою: результат у полі `structured_output` |
| `--allowedTools "Read,Edit,Bash"` | Інструменти, дозволені без запиту |
| `--permission-mode acceptEdits` | Базовий режим дозволів для всього запуску |
| `--append-system-prompt "…"` | Додаткові інструкції поверх стандартних |
| `--continue`, `--resume <id>` | Продовжити попередню розмову |
| `--bare` | Швидкий старт без автопідвантаження хуків, плагінів, MCP і CLAUDE.md (рекомендовано для скриптів і CI) |

<Callout type="tip" title="Пайпи працюють">
`-p` читає stdin, тож можна так: `git diff main | claude -p "знайди опечатки"`. Агенту навіть не потрібен дозвіл на Bash — дані вже прийшли на вхід.
</Callout>

Дозволи можна звужувати до конкретних команд: `--allowedTools "Bash(git diff *),Bash(git commit *)"`. Пробіл перед `*` важливий: без нього `git diff*` збігся б і з `git diff-index`.

## Claude у GitHub Actions

Найшвидше налаштування — команда `/install-github-app` в сесії Claude Code: вона встановить GitHub App, збереже секрет і створить workflow. Мінімальний ручний варіант:

```yaml
name: Claude Code
on:
  issue_comment:
    types: [created]
jobs:
  claude:
    if: contains(github.event.comment.body, '@claude')
    runs-on: ubuntu-latest
    permissions:
      contents: write
      pull-requests: write
      issues: write
      id-token: write
    steps:
      - uses: actions/checkout@v6
      - uses: anthropics/claude-code-action@v1
        with:
          anthropic_api_key: ${{ secrets.ANTHROPIC_API_KEY }}
```

Без `prompt` дія чекає на `@claude` у коментарі (інтерактивний режим). З `prompt` — працює одразу на подію, наприклад за `schedule` (режим автоматизації).

<Callout type="warn" title="Чужий репозиторій — чужі правила">
Без `--bare` запуск `-p` підхоплює хуки й MCP-сервери з `.claude/settings.json` та `.mcp.json` репозиторію — навіть без діалогу довіри. У CI для чужого коду використовуй `--bare`.
</Callout>
