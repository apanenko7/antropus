<TLDR>
- Власний агент потрібен, коли готовий інструмент (Claude Code, чат) не вбудовується у твій продукт чи процес.
- Три шляхи: <Term id="messages-api" /> з інструментами (свій цикл), <Term id="agent-sdk" /> (harness Claude Code як бібліотека), <Term id="managed-agents" /> (Anthropic хостить цикл і пісочницю).
- Почни з найпростішого варіанту, який закриває задачу: часто це один виклик API, а не агент.
</TLDR>

## Чи потрібен агент взагалі?

Агент — це дорожче й повільніше, ніж один запит до моделі. Перед тим як будувати, чесно відповідай:

- задача **багатокрокова** і її важко розписати заздалегідь?
- результат **вартий** більших витрат і часу?
- помилку можна **помітити й виправити** (тести, рев'ю, відкат)?

Якщо хоч одне «ні» — вистачить одного запиту до <Term id="api" /> або простого ланцюжка запитів.

## Три шляхи

| | Messages API + інструменти | Agent SDK | Managed Agents |
| --- | --- | --- | --- |
| Хто пише цикл | Ти (або хелпер Tool Runner у SDK) | SDK | Anthropic |
| Вбудовані інструменти | Немає, лише твої | Файли, Bash, пошук, веб, як у Claude Code | Пісочниця з Bash і файлами + твої інструменти |
| Де працює | Твій сервер | Твій процес чи сервер | Інфраструктура Anthropic (або власна пісочниця) |
| Коли брати | Потрібен повний контроль або вузька задача з кількома своїми функціями | Агент для роботи з файлами й кодом у твоєму застосунку | Не хочеш хостити агента сам; довгі сесії, розклад |

<Callout type="tip" title="Чим SDK відрізняється від API">
Через Messages API ти сам виконуєш інструменти й крутиш цикл. Agent SDK уже містить цикл, інструменти, дозволи, сесії й хуки Claude Code — ти лише ставиш задачу й налаштування.
</Callout>

## Як це виглядає в коді

**Messages API: свій цикл.** Модель просить виклик інструмента, твій код його виконує й повертає результат, доки модель не скаже «готово»:

```ts
import Anthropic from "@anthropic-ai/sdk";

const client = new Anthropic();
const messages: Anthropic.MessageParam[] = [{ role: "user", content: "Який статус замовлення 1842?" }];

while (true) {
  const res = await client.messages.create({
    model: "claude-opus-5-5",
    max_tokens: 16000,
    tools: [orderStatusTool], // твій опис інструмента
    messages,
  });
  messages.push({ role: "assistant", content: res.content });
  if (res.stop_reason !== "tool_use") break; // модель відповіла — виходимо
  messages.push({ role: "user", content: await runTools(res.content) }); // твій код виконує інструменти
}
```

**Agent SDK: цикл уже всередині.** Пакет `@anthropic-ai/claude-agent-sdk`, головна функція — `query()`:

```ts
import { query } from "@anthropic-ai/claude-agent-sdk";

for await (const message of query({
  prompt: "Review utils.py for bugs that would cause crashes. Fix any issues you find.",
  options: { allowedTools: ["Read", "Edit", "Glob"], permissionMode: "acceptEdits" },
})) {
  if (message.type === "result") console.log(`Done: ${message.subtype}`);
}
```

**Managed Agents** (бета): ти один раз створюєш конфігурацію агента (модель, інструкції, інструменти), а потім запускаєш для неї сесії через API. Цикл і пісочниця, де виконуються інструменти, працюють на боці Anthropic.
