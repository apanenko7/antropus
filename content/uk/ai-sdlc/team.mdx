<TLDR>
- Налаштування агента для команди живуть у репозиторії: <Term id="claude-md" />, `.claude/settings.json`, субагенти, <Term id="skill">skills</Term>, <Term id="plugin">плагіни</Term>.
- Код агента рев'ює людина, яка відповідає за злиття. «Це написав AI» не знімає відповідальності.
- Міряй результат (<Term id="lead-time" />, дефекти), а не рядки коду. Впроваджуй поступово: пілот → плейбук → масштаб.
</TLDR>

## Спільне — у репозиторії, особисте — поза git

Коли налаштування агента лежать у репозиторії, кожен новий розробник отримує їх разом із `git clone`:

| Файл | Для чого | У git? |
| --- | --- | --- |
| `CLAUDE.md` | команди тестів, рішення команди, посилання на ADR | так |
| `.claude/settings.json` | спільні дозволи, deny-правила, хуки | так |
| `.claude/agents/*.md` | субагенти команди (наприклад, reviewer) | так |
| `.claude/skills/*/SKILL.md` | повторювані процеси: реліз, міграція | так |
| `CLAUDE.local.md` | твої особисті вподобання | ні, у .gitignore |
| `.claude/settings.local.json` | твої локальні дозволи | ні |

## Політики: секрети й дані

- Секрети не потрапляють у промпти й репозиторій: `.env` у deny-правилах, ключі лише в менеджері секретів.
- Чіткий список, які дані можна давати агенту (код — так, персональні дані клієнтів — ні).
- Небезпечні дії (push у main, деплой, видалення) завжди з підтвердженням людини.
